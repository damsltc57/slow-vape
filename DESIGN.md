# Slow Vape

Slow Vape uses a dark graphite workspace with a compact native navigation rail and a single primary chart. Soft slate and olive reflections carry the reference into the welcome screen. System type is wide and clear, with tabular figures for counts.

Lime indicates an active choice or usable camera feed. Amber indicates an approaching limit. The foreground alert has its own deep red surface and stops demanding attention once acknowledged. History uses a text legend and distinguishes unmonitored periods from monitored zeroes. Native controls retain keyboard navigation.

The logo is an open lime ring around two pause bars. The Dock uses a graphite tile. The menu bar uses the same mark as a monochrome template, dimmed when tracking is paused, and an exclamation symbol at a reached limit.
